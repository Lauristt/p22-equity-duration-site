Run it on your laptop

uv sync --frozen
uv run doit
uv run python src/serve_review.py

Run these commands from the cloned repository. The build retrieves the pinned public authors’ package and generates results locally. The server listens on your own machine only. No personal paths are required; the full build needs your own WRDS credentials and pdflatex.
